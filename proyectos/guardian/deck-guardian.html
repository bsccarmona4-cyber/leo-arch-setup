Diagrama de Casos de Uso

Pipeline de análisis — 6 capas de detección

URL ENTRANTE
    │
    ├── Capa 1: RESOLVER URL
    │     Detecta redirecciones, URL final, cadena completa (máx 10 saltos)
    │     Bloquea IPs privadas (SSRF protection)
    │     Hash para caché (24h TTL)
    │
    ├── Capa 2: WHOIS
    │     Edad del dominio, registrador, fechas de creación/expiración
    │     Dominios < 7 días → peso alto
    │     Dominios < 30 días → peso medio
    │
    ├── Capa 3: PHISHTANK
    │     Consulta base de datos colaborativa de phishing
    │     Si está listado → score directo +50
    │     Operado por Cisco Talos
    │
    ├── Capa 4: BRAND CHECK MX
    │     Distancia Levenshtein vs 15+ marcas mexicanas
    │     SAT, BBVA, Banamex, CFE, Liverpool, Walmart, Amazon MX
    │     Detecta suplantación: "bbva-seguridad.mx" → sospechoso
    │     Contenido de página: menciona "SAT" pero dominio no es .gob.mx → alerta
    │
    ├── Capa 5: LLM (DeepSeek → Groq fallback)
    │     Análisis semántico del contenido de la página
    │     Detecta urgencia, solicitud de datos, lenguaje de estafa
    │     Prompt hardening: 11 patrones de inyección detectados
    │     Temperatura 0.1 para consistencia
    │
    └── Capa 6: FUSIÓN SCORE + LLM
          Ponderación: 30% señales técnicas + 70% análisis LLM
          Score 0-100
          Veredicto: Seguro (0-24) | Sospechoso (25-64) | Fraude (65-100)
          Almacenamiento en DB + caché
