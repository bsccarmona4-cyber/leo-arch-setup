Pruebas de Integración — API /analyze

I-01
POST /api/analyze — URL válida
Body: {"content":"https://...","channel":"web","userHash":"test"}
Esperado: 200 + veredicto + score
I-02
POST /api/analyze — body inválido
Body: {"foo":"bar"}
Esperado: 400 + error message
I-03
POST /api/analyze — rate limit excedido
10 requests desde misma IP en 1 minuto
Esperado: 429 + rate limit message
I-04
POST /api/analyze — SQL injection
Body con "content": "'; DROP TABLE analyses;--"
Esperado: 400 o 200, nunca error SQL
I-05
POST /api/analyze — content demasiado grande
Body con 200KB de datos
Esperado: 413
I-06
POST /api/analyze — método incorrecto
GET, PUT, DELETE a /api/analyze
Esperado: 405
I-07
POST /api/analyze — Content-Type incorrecto
Header: Content-Type: text/plain
Esperado: 415
I-08
GET /api/stats
Sin parámetros
Esperado: 200 + totalAnalyses

Flujo de Prueba — Análisis de URL

POST /api/analyze
│
├─ checkMethod (405 si no es POST)
├─ checkContentType (415 si no es JSON)
├─ checkRateLimitByIp (429 si excede 10/min)
├─ readBody (413 si > 100KB)
├─ JSON.parse
├─ sanitizeBody (limpia caracteres de control)
├─ analyzeSchema.parse (Zod validation — 400 si inválido)
├─ detectInjection (400 si detecta prompt injection)
├─ checkRateLimit (429 si excede por usuario)
│
├─ analyzeUrl()
│ ├─ isPrivateHost (SSRF protection)
│ ├─ checkCache (24h TTL)
│ ├─ resolveUrl (máx 10 redirecciones)
│ ├─ fetch page content (timeout 5s, máx 500KB)
│ ├─ scoreUrlSignals (WHOIS, PhishTank, Brand MX)
│ ├─ callLLM (DeepSeek → Groq fallback)
│ └─ fusionScore (30% técnico + 70% LLM)
│
├─ db.insert('analyses')
├─ upsert url_cache
├─ increment_analysis_count
│
└─ 200 { verdict, score, response }
