# Nota: Cómo escribir mejores prompts

## Principios clave

1. **Contexto primero**: más contexto → mejores respuestas.
2. **Rol explícito**: "eres experto en X" cambia el tono y la profundidad.
3. **Pequeños pasos**: divide tareas complejas (separación de procesos).
4. **Formato definido**: pedir estructura concreta evita respuestas vagas.
5. **Iterar**: prueba → guarda → ajusta → repite.

## Checklist antes de enviar

- [ ] ¿Definí el rol?
- [ ] ¿El objetivo es claro y medible?
- [ ] ¿Di qué formato de salida quiero?
- [ ] ¿Puse restricciones (largo, temas a evitar)?
- [ ] ¿Di criterios de éxito?

## Errores comunes

- Prompts vagos → respuestas genéricas.
- Pedir todo de una vez → la IA se pierde.
- No dar ejemplo del formato esperado.
- No iterar ni guardar qué funcionó.
