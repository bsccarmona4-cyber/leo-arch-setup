# 🤖 IA Playground

Entorno privado para practicar prompts, pruebas de IA y experimentos.

## 📁 Estructura

```
ia-playground/
├── prompts/      → Tus prompts escritos (cada uno en su propio .md)
├── ejemplos/     → Prompts de ejemplo ya redactados
├── resultados/   → Respuestas / salidas que obtengas
├── plantillas/   → Plantillas reutilizables de prompts
├── notas/        → Apuntes, aprendizajes, ideas
└── scripts/      → Scripts de automatización / testing
```

## 🚀 Cómo usar

1. Escribe tu prompt en `prompts/`, usa la plantilla de `plantillas/` como base.
2. Ejecuta tu prompt (con goose, CLI, API, etc.).
3. Guarda la respuesta en `resultados/` con nombre descriptivo.
4. Anota qué funcionó / no funcionó en `notas/`.

## 📝 Plantilla rápida

Copia `plantillas/00_prompt_base.md` → `prompts/mi_prompt.md` y rellena.

## 💡 Consejos

- Da contexto: rol, objetivo, formato esperado.
- Sé específico: qué quieres, para qué, con qué restricciones.
- Guarda versiones: v1, v2... para ver iteraciones.
- Registra resultados para comparar qué prompt funciona mejor.
