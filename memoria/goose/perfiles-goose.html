⚠️ Notas importantes

  • Los MCPs via npx -y se ejecutan sin instalar (npx cache). Primera vez puede tardar 2-3 segundos.
  • BlackMountNLP necesita pip install blackmount-nlp-mcp una vez.
  • Time y Git necesitan pip install mcp-server-time mcp-server-git (o python -m funciona si están instalados).
  • Si un MCP no arranca, verifica que el comando/path existe con which o test -f.
  • POWER no incluye Brave Search ni Pinecone ni Kubernetes (necesitan API key o no aplican para uso general).
  • Para agregar más MCPs: usa A2ASearch "find MCP server for X" y agrégalo al config.
