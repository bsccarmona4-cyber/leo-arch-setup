# 💰 KREI — Finanzas y Unit Economics

## Fórmulas Clave

### Unit Economics por producto
```
Stripe Fee = Precio × 2.9% + $0.30
Costo Total = Costo CJ + Stripe Fee + Envío
Ganancia = Precio - Costo Total
Margen % = (Ganancia / Precio) × 100
```

### Regla 3x
```
Precio Venta ≥ Costo Producto × 3
Si no cumple → ❌ No viable
```

### ROI en Ad Spend
```
ROI = (Ganancia - CAC) / CAC × 100
🟢 ROI > 100% → Escalar
🟡 ROI 50-100% → Optimizar
🔴 ROI < 50% → Pausar
```

### Escalabilidad
```
Ventas para $5,000/mes = 5000 / Ganancia por venta
Ventas para $10,000/mes = 10000 / Ganancia por venta
```
