# KREI Lite Profile

Activate this skill for quick, lightweight sessions without heavy MCP overhead.

## Instructions

When this skill is active:

1. **Directo**: respuestas concisas, mínimo preámbulo.
2. **Sin sub-agentes** a menos que sea estrictamente necesario.
3. **MCPs mínimos**: solo herramientas built-in de CodeWhale.
4. **Sin tree-of-thought** obligatorio — usa juicio.
5. **Tareas rápidas**: ediciones simples, lecturas, búsquedas.

## Disabled (para este perfil)
- Sequential Thinking
- Memory
- Puppeteer/BrowserMCP
- Análisis heavy

## Skills cargados
- krei-arbol-pensante (opcional, solo si el problema lo requiere)
