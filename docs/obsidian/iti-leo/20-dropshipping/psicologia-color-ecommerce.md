# 🧠 Psicología del Color en Ecommerce

## Colores y su efecto en ventas

| Color | Efecto | Quién lo usa |
|---|---|---|
| 🔴 Rojo | Urgencia máxima, acelera pulso | Netflix, YouTube, Coca-Cola, KFC |
| 🟠 Naranja | Acción sin agresividad | Amazon, Home Depot, Fanta |
| 🟡 Amarillo | Optimismo + atención | McDonald's, Snapchat, IKEA |
| 🟢 Verde | Confianza + tranquilidad | Starbucks, Spotify, Whole Foods |
| 🔵 Azul | Máxima confianza, disminuye ritmo cardíaco | PayPal, Visa, Facebook, Intel |
| ⚫ Negro | Lujo absoluto, exclusividad | Supreme, Chanel, LV, Apple |
| ⚪ Blanco | Minimalismo + legibilidad | Apple Store, COS, Muji, Glossier |

## Mejores combinaciones para CTA
| Contexto | Combinación | CTR |
|---|---|---|
| Compra impulsiva | 🔴 Rojo sobre 🟡 Amarillo / ⚪ Blanco | +32% |
| Alta confianza | 🟢 Verde sobre ⚪ Blanco | +21% |
| Lujo + exclusividad | ⚪ Blanco sobre ⚫ Negro | +18% |
| Urgencia moderada | 🟠 Naranja sobre ⚪ Blanco | +25% |
| Premium CTA | 💛 Dorado sobre ⚫ Negro | +15% |

## Aplicado a KREI
- Primario: Rojo `#DC2626` (urgencia/compra)
- Fondo: Blanco `#FFFFFF` (confianza)
- Texto: Negro `#1A1A1A` (premium)
- Acento: Dorado `#F59E0B` (estrellas, badges)
- Dark sections: `#1A1A2E` (high-ticket)
