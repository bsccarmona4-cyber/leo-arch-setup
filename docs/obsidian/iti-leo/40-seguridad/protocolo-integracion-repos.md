# 🔒 Protocolo de Integración de Repos GitHub

**Skill asociada:** `krei-integracion-repos`

1. Leo pasa link de GitHub
2. Goose inspecciona (stars, autor, issues)
3. Goose clona en `/tmp/` y escanea malware
4. Si ✅ → integra y documenta en `30-arsenal/`
5. Si ❌ → reporta y no integra
