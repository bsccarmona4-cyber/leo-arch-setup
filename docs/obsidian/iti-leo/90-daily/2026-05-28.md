# 💰 UNIT ECONOMICS

**Fórmula final:**
- Precio venta = costo CJ × **2.8**
- Stripe fee = (precio_venta × 0.029) + $0.30
- Envío: $4 si precio_venta < $50, **$0 si ≥ $50** (free shipping)
- Ganancia neta = precio_venta - costo_CJ - envío - Stripe
- Margen mínimo aceptable: **35%**

**Resultados:** Todos los productos entre **44.9% y 61.1%** de margen ✅

## CJ API — Endpoints útiles
- `POST /api2.0/v1/authentication/getAccessToken` — Token JWT
