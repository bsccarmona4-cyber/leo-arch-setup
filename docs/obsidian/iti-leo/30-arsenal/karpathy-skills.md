## Principios clave
1. **Think before coding** — No asumas, no escondas confusión, explicita tradeoffs
2. **Simplicity first** — Mínimo código que resuelve el problema
3. **Surgical changes** — Cambios precisos, no refactors masivos
4. **Surface assumptions** — Explicita lo que das por sentado
5. **Verifiable success** — Define criterios de éxito medibles
