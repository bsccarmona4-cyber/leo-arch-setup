## Skills de Ingeniería

| Skill | Qué hace |
|---|---|
| `grill-with-docs` | Sesión de escrutinio + documentación (CONTEXT.md, ADRs) |
| `triage` | State machine de roles para issues |
| `tdd` | Red-green-refactor con vertical slices |
| `to-issues` | Divide planes en issues ejecutables |
| `to-prd` | Crea PRDs desde la conversación |
| `diagnose` | Debug disciplinado para bugs difíciles |
| `prototype` | Prototipado rápido |
| `improve-codebase-architecture` | Mejora de arquitectura |
| `zoom-out` | Vista general del proyecto |

## Cómo las uso

**Autoselección:** Yo mismo elijo la skill según el contexto. Por ejemplo:
- Tarea de Python → `tdd` o `diagnose`
- Planeando dropshipping → `grill-me` o `grill-with-docs`
- Documentando → `to-prd` o `handoff`
