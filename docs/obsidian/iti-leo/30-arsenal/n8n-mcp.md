## Descripción
MCP server que permite a cualquier agente IA (Claude Code, Windsurf, Cursor) construir workflows de n8n directamente desde el chat.

## Instalación
```bash
npx n8n-mcp
```

## Uso
Desde goose, configurar como extensión stdio apuntando al binario. Permite crear y modificar workflows de n8n sin tocar la UI.
