# 🧰 BrowserMCP — Navegador Automatizado para IA

**Estrellas:** ⭐ 6,594
**Seguridad:** ✅ Seguro
**Autor:** BrowserMCP

## Descripción
MCP server que permite a agentes IA controlar un navegador web real (Chromium). Útil para:
- Automatizar acciones en webs
- Extraer datos de páginas con JS
- Testing de UI
- Interacciones complejas que requieren login

## Instalación
```bash
npx mcp-server-browsermcp
```
