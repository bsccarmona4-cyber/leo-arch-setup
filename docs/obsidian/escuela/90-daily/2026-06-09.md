### Lo que se construyó hoy

**Backend (/api/analyze)**
- Pipeline 6 capas: redirect resolve → multi-señal scoring → LLM → fusión → caché → respuesta
- Score multi-señal: WHOIS, PhishTank, Levenshtein (brands MX), SSL, formularios, urgencia
- DeepSeek con prompt hardened contra injection
- Cache 24h en Supabase
- Rate limiting por IP + por usuario

**Hardening seguridad**
- Zod schemas en todas las rutas
- Validación método HTTP (405) + Content-Type (415)
- Sanitización body (control chars, max length)
- Rate limit por IP via Supabase (sha256)
- Security headers (X-Content-Type-Options, X-Frame-Options, CSP, etc)
- Prompt injection: delimitadores <CONTENIDO_EXTERNO>, 11 patrones detectados, validation zod output
- LLM input truncado: URLs 500 chars, emails 3000 chars
- Errores genéricos (sin stack, sin rutas, sin keys)
