3. MODELO ENTIDAD-RELACION
--------------------------------------------------------------------------------

3.1 Diagrama

    +------------------+         +-------------------+
    |     ALUMNO       |         |      CURSO        |
    |  (Entidad fuerte)|         |  (Entidad fuerte) |
    +------------------+         +-------------------+
    | *IDAlumno (PK)   |         | *IDCurso (PK)     |
    | Nombre           |         | Nombre            |
    | ApellidoPaterno  |         | Duracion          |
    | ApellidoMaterno  |         | Costo             |
    | CURP (UNIQUE)    |         +-------------------+
    | Celular          |                  |
    +------------------+                  |
             |                            |
             | 1                        1 |
             |                            |
             | N                        N |
             |     +------------------+   |
             +---->|   INSCRIPCION    |<--+
                   | (Entidad debil)  |
                   +------------------+
                   | *Folio (PK)      |
                   | IDAlumno (FK)    |
                   | IDCurso (FK)     |
                   | Costo            |
                   | Duracion         |
                   +------------------+

3.2 Cardinalidad
    - Alumno - Inscripcion: 1 a N (un alumno puede tener muchas inscripciones)
    - Curso - Inscripcion: 1 a N (un curso puede tener muchas inscripciones)
    - Inscripcion es entidad debil: no puede existir sin un alumno y un curso

3.3 Integridad referencial
    - FOREIGN KEY (IDAlumno) REFERENCES Alumno(IDAlumno)
        ON DELETE CASCADE ON UPDATE CASCADE
    - FOREIGN KEY (IDCurso) REFERENCES Curso(IDCurso)
        ON DELETE CASCADE ON UPDATE CASCADE
    - PRAGMA foreign_keys = ON (se activa en cada conexion)


4. DEFINICION DE TABLAS (DDL)
--------------------------------------------------------------------------------

4.1 Tabla ALUMNO

    CREATE TABLE IF NOT EXISTS Alumno (
        IDAlumno         INTEGER PRIMARY KEY AUTOINCREMENT,
        Nombre           TEXT    NOT NULL,
        ApellidoPaterno  TEXT    NOT NULL,
        ApellidoMaterno  TEXT    NOT NULL,
        CURP             TEXT    NOT NULL UNIQUE,
        Celular          TEXT    NOT NULL
    );

    Campo            | Tipo    | Nulo | Restriccion
    -----------------+---------+------+---------------------------
    IDAlumno         | INTEGER | No   | PRIMARY KEY AUTOINCREMENT
    Nombre           | TEXT    | No   | NOT NULL
    ApellidoPaterno  | TEXT    | No   | NOT NULL
    ApellidoMaterno  | TEXT    | No   | NOT NULL
    CURP             | TEXT    | No   | NOT NULL, UNIQUE
    Celular          | TEXT    | No   | NOT NULL

4.2 Tabla CURSO

    CREATE TABLE IF NOT EXISTS Curso (
        IDCurso  INTEGER PRIMARY KEY AUTOINCREMENT,
        Nombre   TEXT    NOT NULL,
        Duracion TEXT    NOT NULL,
        Costo    REAL    NOT NULL
    );

    Campo    | Tipo    | Nulo | Restriccion
    ---------+---------+------+---------------------------
    IDCurso  | INTEGER | No   | PRIMARY KEY AUTOINCREMENT
    Nombre   | TEXT    | No   | NOT NULL
    Duracion | TEXT    | No   | NOT NULL
    Costo    | REAL    | No   | NOT NULL

4.3 Tabla INSCRIPCION

    CREATE TABLE IF NOT EXISTS Inscripcion (
        Folio     INTEGER PRIMARY KEY AUTOINCREMENT,
        IDAlumno  INTEGER NOT NULL,
        IDCurso   INTEGER NOT NULL,
        Costo     REAL    NOT NULL,
        Duracion  TEXT    NOT NULL,
        FOREIGN KEY (IDAlumno) REFERENCES Alumno(IDAlumno)
            ON DELETE CASCADE ON UPDATE CASCADE,
        FOREIGN KEY (IDCurso)  REFERENCES Curso(IDCurso)
            ON DELETE CASCADE ON UPDATE CASCADE
    );

    Campo    | Tipo    | Nulo | Restriccion
    ---------+---------+------+------------------------------------------
    Folio    | INTEGER | No   | PRIMARY KEY AUTOINCREMENT
    IDAlumno | INTEGER | No   | NOT NULL, FK -> Alumno(IDAlumno) CASCADE
    IDCurso  | INTEGER | No   | NOT NULL, FK -> Curso(IDCurso) CASCADE
    Costo    | REAL    | No   | NOT NULL
    Duracion | TEXT    | No   | NOT NULL

6. CATALOGO DE FUNCIONES

6.1 Capa de datos

    conectar()               | Abre conexion a SQLite y activa foreign keys.
                             | Retorna un objeto Connection.
    crear_tablas()           | Ejecuta los CREATE TABLE IF NOT EXISTS para

8. CONSULTAS SQL UTILIZADAS
--------------------------------------------------------------------------------

8.1 Consulta de inscripciones con JOIN

    SELECT i.Folio,
           a.IDAlumno || ' - ' || a.Nombre || ' ' || a.ApellidoPaterno
               || ' ' || a.ApellidoMaterno AS Alumno,
           c.IDCurso || ' - ' || c.Nombre AS Curso,
           i.Costo,
           i.Duracion
    FROM Inscripcion i
    JOIN Alumno a ON i.IDAlumno = a.IDAlumno
    JOIN Curso  c ON i.IDCurso  = c.IDCurso

    Esta consulta une las tres tablas para mostrar en la tabla de
    inscripciones los nombres del alumno y del curso en lugar de sus IDs.

8.2 Activacion de llaves foraneas

    PRAGMA foreign_keys = ON

    SQLite no activa las llaves foraneas por defecto. Este pragma se
    ejecuta en cada conexion para garantizar la integridad referencial.
