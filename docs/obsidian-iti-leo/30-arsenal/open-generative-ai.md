## Descripción
Estudio self-hosted de generación de imagen y video AI con 500+ modelos (Flux, Midjourney, Kling, Sora, Veo, Seedance). Sin filtros de contenido, sin ecosistema cerrado, sin suscripciones. Alternativa open-source a plataformas de AI video/imagen.

## Skills/Agentes
- App Next.js con UI de studio (Image, Video, Audio, Cinema, etc.)
- Desktop app: Electron (macOS, Windows)
- MCP server y CLI (muapi-cli)
- Workflows: nodos de n8n, ComfyUI, Vibe Workflow

## Requisitos para usar
- **API key obligatoria**: [MuAPI](https://muapi.ai/pricing) — créditos pay-as-you-go
- Versión hosted gratis en muapi.ai/open-generative-ai
- Self-host con Node.js + Docker
