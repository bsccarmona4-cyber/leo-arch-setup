## Descripción
Alternativa open source a Semrush y Ahrefs. SEO tool con MCP server para agentes AI. Workflows: keyword research, rank tracking, competitor insights, backlinks, site audits, AI visibility. Soporta self-hosting (Docker o Cloudflare Workers).

## Skills/Agentes
- MCP server con herramientas SEO (keyword research, site audit, backlinks, etc.)
- Agent skills pre-construidos para Claude Code, OpenClaw, Hermes
- Dashboard web + API

## Requisitos para usar
- **API key obligatoria**: [DataForSEO](https://dataforseo.com/?aff=255379) — créditos free para empezar
- Self-host vía Docker: `docker compose up` (recomendado)
- Alternativa cloud: openseo.so ($10/mes)
