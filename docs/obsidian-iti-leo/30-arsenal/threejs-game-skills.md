## Descripción

## Skills instaladas
- `threejs-game-director` — Entrypoint para creación de juegos completos
- `threejs-gameplay-systems` — Gameplay, game design, combat, game-feel
- `threejs-aaa-graphics-builder` — Gráficos AAA-style (procedural models, shaders)
- `threejs-3d-generator` — Generación de assets 3D vía Tripo API
- `threejs-image-generator` — Generación de imágenes/conceptos
- `threejs-audio-generator` — Generación de audio vía ElevenLabs
- `threejs-game-ui-designer` — UI para juegos (HUD, menús, overlays)
- `threejs-debug-profiler` — Debugging y profiling (draw calls, memoria, FPS)
- `threejs-qa-release` — QA y release readiness
